DeepSeek Harness我一口气装了16个插件，最离谱的那个在播页游广告_腾讯新闻

2026年8月18日
| 阅读

问AI · 开源框架插件上千个，对AI工具定制化有何启发？

你好，我是蔚公子，毕业ALL in AI，专注于 AI 提效/企业赋能/教育

点击👇关注我，分享真正能落地的AI方案，让企业和个人把AI用好

昨天聊完 DeepSeek Harness，社群里好几个圈友问同一件事：

装是装上了，然后呢？

问得挺对。因为你装完就会发现，界面干干净净，什么都没有🤔

传个文件不行，粘张图不行，想在输入框里 @ 一个文件也不行。

当然，这不怪它。官方自己在仓库里写着还是开发预览版，后面可能还有大改动。它的思路本来也不是给你一个装好的成品，而是把骨架给你，剩下的自己往上装。

所以我这两天把插件生态摸了一遍，一口气装了16个好用插件，整理了一份清单。

哪些装了才顺手，哪些看情况，哪些我劝你别乱装，还有一件大部分人都会忽略的事，全在下面👇

一、先把它装上

安装昨天那篇来了！DeepSeek Harness 四轮实测，以后你的 AI 工具可能是你自己造的「附安装教程」已经讲过了，这里再放一遍，最省事的办法是把这段话直接丢给本地的 Agent：

帮我安装并启动 DeepSeek Harness。项目地址：

https://github.com/deepseek-ai/deepseek-harness 先检查运行环境，缺什么装什么。 然后运行 npx @deepseek-ai/dsh web，并打开网页端。

浏览器弹出界面之后，在设置里填上 DeepSeek 的 API Key，选好工作目录，就能开始了。

二、插件是怎么装的

有个事先说清楚，插件不是你跟模型报个名字它就自己长出来的。

最后执行的还是这条命令：

dsh plugin –profile web add <插件包名或 github:作者/仓库>

如果懒得敲，直接跟它说也行：

帮我安装 xxx 插件到 web profile。 先核对仓库和安装脚本，把命令发给我确认。 安装后验证 plugin list，并提醒我重启。

顺带说个我自己随手测出来的事。我一开始做好了心理准备，这么多插件一个个装一个个试，怎么也得搭进去一整天。

结果装到一半发现，它能并发！

好几个任务可以同时开着跑，一边装一边测，五个小时左右我就全过了一遍。

代价也有，Token 是真烧😅 但比起省下来的时间，我觉得这笔账划算。

好，下面进正题。

三、第一批，装了才算齐全

dsh-market，插件市场。搜索安装升级卸载都能在设置里点完。

这个我建议你第一个就装。装完之后，不少插件在界面上点两下就装好了，省事不少。当然也有一些比较复杂的，还是得自己动手👌

ModLens，给纯文本模型外挂一双眼睛。粘图、识别文字、看图表都行，是这个生态里第一个视觉插件，维护得也比较成熟。

不过它自己不带视觉能力，你还得配一个能看图的接口给它。

dsh-at-file，在输入框打个 @ 就能搜工作区的文件并引用。这是原生界面最明显的缺口之一，我个人觉得算刚需。

dsh-files，拖拽或者上传文件，让它去读 TXT、PDF、Word 和 Excel。带会话隔离和格式检测，也能限制大小，比你把文件路径硬塞进输入框规矩多了。

dsh-office-tools，我让它生成一份 Word、一份 PPT 和一个 Excel，全都出来了，而且是真能下载下来的那种。好处是纯 JS 处理，不用你本机装 Office。

当然，项目还比较新，复杂排版就别指望了。

四、第二批，看情况装

dsh-find-plugin，你直接说我要什么功能，它去帮你找插件、把安装命令给你。

这里提醒一句，它是帮你找的，不是帮你审的🧐

dsh-explorer，给界面加上文件树和 Git 状态，还有改动对比和文件预览。功能挺实用，而且基本是只读的，比较安全。麻烦的地方是安装要装两个部分。

dsh-genui，让回复里直接长出图表、表单和流程图这些东西。

我丢了个 A 等于 10、B 等于 20、C 等于 15 的柱状图需求给它，它给我渲染出来了。

dsh-turn-rewind，把对话和文件恢复到某条消息之前。它恢复前会先预览有哪些文件要变、要你确认、还给你留个救援点，比你自己手动回滚靠谱。

dsh-message-edit，编辑已经发出去的消息，重试，重新生成，还给你保留一条分支式的时间线。注意它只管对话，已经写进硬盘的文件它撤不了。

dsh-usage-stats，统计花了多少 Token，缓存命中多少，调用了几次，还能看账户余额，界面上还有个热力图。有个好处是，装完它还能自动把历史会话补上。

这个插件我感觉算是实用的，不然烧了多少token都不知道👌

五、第三批，重度用户再考虑

dsh-agent-teams，组一个多 Agent 的团队，拆任务排依赖再分工，面板上还能看进度。功能不错，但Token 烧得也是真不算少。

dsh-memento，跨会话的本地记忆，存在本地数据库里，每次要写什么进去都得你点头。

它有个审计面板，什么时候存的、存了什么、待审批的有哪些，一条条列得清清楚楚。

缺点是用久了旧东西也会干扰新任务，得定期收拾。

dsh-llm-fallbacks，主力模型限流、欠费或者报错的时候自动切备用的。

这个有个小坑，装完默认是不生效的，你还得自己配好几个模型、打开开关，最后设好切换顺序。

当然，这里要说一点，插件有些是在变化的，所以效果如果和文中有一些差别，是正常现象。

六、说件大部分人会忽略的事

必须要提一嘴的是，社区插件跑起来的时候，用的是你本机的权限。

它能读你的文件，能碰你的凭据，能走网络。

进了插件市场，不代表通过了安全审计 这句话是官方的插件索引里自己写的，不是我吓唬你。

所以装之前，至少花半分钟看一眼仓库、安装脚本和最近更新时间。

这一段我觉得比上面十几个插件加起来都重要🥸

七、正经的说完了，再看几个好玩的

什么，你以为这就结束了？Nonono！

除此之外，我还翻到了几个挺有意思的项目，也一并分享给大家。

dsh-ads，给 AI 推理强行插播页游广告的插件。

这是我这一圈装下来最不正经、也最上头的一个。

装完那一下我直接笑出声。整个界面糊满了广告，两边挂着、右下角弹着、中间还飘着，一秒梦回 2005 年的门户网站😦

最有味儿的是那几张页游广告。

拟人化的 DeepSeek 小姐姐骑着马举着剑，配上贪玩蓝鲸、是兄弟就来蹭我、上线送 VIP15 和 88888 Token，那个年代感是真的到位。

不过最绝的还不是这些。

右下角有个 DSH 跑分中心，煞有介事地告诉我，本次启动耗时 1.80 秒，超过全国 63.7% 的用户，全国排名第 72,600 名。

我一看，行啊，那就点一下试试。

然后它就跟当年那些流氓软件一模一样，跳出来说你有病毒了，接着把我引到 GitHub，让我去给它点个 Star🥸

这一手我是真服了。

要说一点，也不是全无代价，有几个广告位是关不掉的，稍微有点小恶心。但话说回来，这本来就是个恶搞项目，太规矩了反而不对味。

所以它确实能用，模型也确实在后台好好干活呢，只是你的回答得等广告播完才给你显示。效率提升是负数，节目效果接近满分。

第二个是dot-skill，把一个人的经验做成 Skill。

这个项目原来叫 colleague-skill，现在升级成了 dot-skill。

你给它聊天记录、工作文档和邮件，或者你对某个人的描述，它会试着提炼出这个人的工作方法、判断标准和说话习惯，最后做成一个能被 Agent 调用的 Skill。

它不是训练模型，也不是真复活一个人，本质上是资料分析加人格提炼再加上生成 Skill 的一套流程。

这个功能好玩是好玩，但聊天记录、邮件和公司文档里都可能有隐私。没经过本人同意的资料，最好别拿去做。

八、蔚公子的洞察

它现在最大的优点和最大的问题，其实是同一件事。

什么都能装，但什么都得自己装。

这话听着像吐槽，可你换个角度想，它是把选择权还给你了。

以前你用一个 Agent 产品，能力边界是别人画好的，人家给什么你用什么，想多要一点，只能等它更新。现在骨架摆在这儿，你缺什么补什么，团队要什么装什么，实在没有，你还能自己写一个塞进去。

我装到一半的时候，其实有点恍惚。

一个开源没几天的框架，插件已经上千个了，连给 AI 强行插播页游广告这种东西都有人做出来，还做得像模像样。这个生态的生长速度，比框架本身更吓人。

所以我的判断是，它现在或许不够好用，门槛也实打实地摆在那儿。你要是只想开箱即用，那先看着，等生态和文档再长一长。

但你要是开发者，或者手上有明确的工作流想搭，可以现在就上手试试。不是因为它今天有多好用，是因为这套东西的天花板确实高，而生态起来的时候，先摸熟的人永远占便宜。

工具是好工具，就是现在——还得你自己动手🔥
