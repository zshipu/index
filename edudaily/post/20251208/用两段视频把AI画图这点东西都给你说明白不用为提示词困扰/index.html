用两段视频把AI画图这点东西都给你说明白，不用为提示词困扰

2025年12月14日
| 阅读

文章发过，好好看的不多……从头到尾看完的就更少了……那我就发个视频版投喂好了。

Nano Banana 画图提示词写得好，是真能吃到流量挣到钱的

教你几个我自己在做图片应用时用的提示词技巧，你也能出爆款

现在的画图已经不是简单的画图了，它真的可以做很多东西的啊，同志们！重视起来啊！

1，这个视频非常有价值，它揭示了一个许多高手心照不宣的**“逆向工程”**玩法：如何利用现有的高质量图片，反推提示词（Prompt），再生成属于你的作品。

这个方法的本质是：以图生词 -> 以词生图。

涉及到的两段提示词：

自然语言版本：

你是一个专业的AI图像提示词工程师，任务是从参考图片逆向生成一个高度还原原图的中/英文提示词。

请仔细观察我上传的图片，生成一个适合Midjourney、ChatGPT-4o、Nano Banana等模型使用的详细中/英文prompt，要求：

- 精确描述主体、姿势、表情、服装、配饰、场景、构图等所有关键元素

- 包含艺术风格、线条特点、颜色调色板、光照、纹理、质感等

- 如果图片有明显艺术家签名或独特风格，请明确提及（如 “in the style of [artist]” 或 “artist-signed style”）

- 使用自然流畅的描述顺序：先主体 → 细节 → 服装/配饰 → 背景/构图 → 整体风格和氛围

- 合理使用权重语法，如 (important element:1.2)、[less important]

- 提示词长度控制在500词以内，精炼但信息完整 

请只输出最终的完整中文提示词，不要加任何解释或其他文字。

json 版本：

你是一个专业的AI图像提示词工程师，擅长将图片元素结构化拆解。

请仔细分析我上传的这张图片，将所有视觉元素严格按照以下JSON格式输出（字段名称和顺序不可更改，不要添加额外字段或解释）：

{

  “subject”: “主要主体描述，包括人物/物体、姿势、朝向、整体特征”,

  “facial_details”: “面部或焦点区域细节（如表情、五官、妆容、情绪），如果无面部则描述对应焦点”,

  “hair_and_headwear”: “发型、头饰、帽子等细节（如适用）”,

  “clothing_and_accessories”: “服装、配饰、道具的完整描述，包括颜色、图案、材质感”,

  “composition”: “整体构图、布局元素、前景背景关系、边框或特殊排版”,

  “style”: “艺术风格描述（如写实、插画、线稿、油画、极简等），包括线条、上色方式、笔触”,

  “artist_influence”: “如果有明显艺术家签名或风格，写艺术家名字或类似风格描述，否则写’none’”,

  “color_palette”: “主要颜色及其使用部位，整体色调（如暖色、冷色、高对比）”,

  “lighting_and_mood”: “光照特点、氛围、情绪”,

  “texture_and_effects”: “纹理、颗粒、做旧、特效等细节”,

  “background”: “背景描述（颜色、元素、复杂度）”

}

请只输出纯JSON代码块，不要加任何其他文字、解释或markdown符号。

2，这个视频是上一个的进阶版（Part 2），解决了一个更实际的痛点：“即使我逆向出了提示词，如果要换成我自己的照片（或者猫、狗、房子），手动改词太累了，能不能全自动？”

这个方法的本质是：特定风格提示词 + 模版化指令 -> 通用风格模版 -> 你的照片 + 模版 = 你的风格照

涉及到的提示词：

请将以下这个具体的图像生成提示词改造为一个高度通用的提示词模板：原提示词：{输入原提示词的内容}

要求：主体完全严格根据用户上传的参考图像生成（添加描述：严格忠实于上传参考图片的主体外形、细节、特征、质感、姿态和整体气质，权重至少1.6以上）。

去除或抽象化原提示词中所有具体的主体特征（如特定性别、发型、五官、服装、动作等），改为中性、灵活的描述，让模型能自动适应任意类型参考图（人、动物、建筑、物体、抽象等）。

如果原提示词中有不适合非人类主体的元素（如红唇、眼睛、嘴巴、手等），请改为“若适合则…”或抽象化为“相应区域添加…”或“抽象几何元素点缀”。

全力保留原提示词的核心艺术风格、构图方式、色彩限定、质感效果、灯光、布局、纵横比等所有风格相关描述，不要删减或改动这些部分。

输出结果必须是纯中文、结构清晰、直接可复制使用的完整提示词模板。

如果原提示词中有牌面、边框、文字等固定布局元素，必须完整保留。

最后加上“纵横比 X:Y”（如果原提示词有的话）或其他必要参数。

请直接输出改造后的完整提示词模板，不要加额外解释。

这个雪景复古简约风的我也分享给你：

极简主义插图风格的复古旅行海报，以河南南阳标志性古建筑——南阳武侯祠（卧龙岗）山门的正面视角作为中心构图，描绘刚下过一场轻雪后的冬日景象。建筑结构被高度简化为纯扁平矢量图形，采用粗黑手绘轮廓线条，带有轻微不规则变化。

仅限色盘：

温暖的橙红色（用于武侯祠山门建筑主体、墙面和梁柱）

柔和的灰绿色（用于背景天空）

纯白色（覆盖在屋顶瓦片、地面和台阶上的积雪）

少量灰色（用于细节点缀，如门钉或匾额轮廓）

天空散落着轻轻飘落的雪花，大面积留白营造干净通透感。俏皮却优雅的构图，建筑元素比例小巧精致，置于画面中央。整体带有轻微纸张纹理质感，融合现代数字插图与经典复古海报美学，强调干净的水平线条。

文字：

第一行“NANYANG.” 全大写，简洁粗体的打字机或无衬线字体，黑色；

第二行紧接其下“南阳”两个字，手写体书法风格（柔和流畅的毛笔手写字体，略带艺术感），黑色。

整体文字组居中置于海报最底部，与上方留出充足空白，尺寸最小化，不抢主体风头。

高分辨率，竖版海报构图，宁静冬季氛围，无人物、无多余元素，极致简约设计。

这个技巧的核心在于「抽象化」。普通的提示词写得越死（比如“长发女生”），泛用性越差。通过这个“通用化改造指令”，你强迫 AI 忘记具体的“长发女生”，而只记住“画法是极简线条，颜色是红黑配”，从而让这个风格可以套用在万物之上。

3，纯想法从零到一～利用 AI 给自己找灵感，能把你的“一句话想法”瞬间变成“大师级提示词”。

核心逻辑是：你提供“骨架”（想法），强制 AI 脑补“血肉”（细节），并用“容器”（结构）规范输出。

我用的多的 3 个方式：

-跟视频 1 里用 json 格式一样，JSON 结构填空

“我需要一个高质量的AI 画图用的提示词。我的核心主题是：{输入你的主题，如：雨中的老房子，真实摄影的}。

请发挥你的想象力，自动填充以下 JSON 结构中的所有细节，使其成为一幅极具艺术感和画面张力的作品。不要留空，细节越丰富越好：

{

“subject”: “核心主体描述（外形、动作）”,

“environment”: “环境与背景（天气、时间、地点）”,

“composition”: “镜头语言与构图（景别、视角、几何关系）”,

“lighting”: “电影级布光（光源方向、色温、对比度）”,

“style”: “具体的艺术流派或艺术家风格（如 ‘in the style of…’）”,

“color_palette”: “色板（主色、辅色、点缀色）”,

“mood”: “情绪氛围关键词”,

“texture”: “材质与肌理感”

}

填充完毕后，请将这些内容组合成一段连贯的中/英文的提示词。”

-不停的追问，这样 AI 会给你具体的画面选项，你只需要做“选择题”，而不是“填空题”。

“你现在是一位电影美术指导和视觉艺术家。我有一个初步的画面想法：{画一只神器的猫}。请你不要直接生成提示词，而是先利用你的专业知识，从以下 5 个维度帮我进行创意通过和细节扩充，向我描述 3 种不同风格的画面方案供我选择：艺术风格（如：赛博朋克、吉卜力手绘、极简包豪斯等）光影氛围（如：雷德利·斯科特式的冷峻蓝光、维斯·安德森式的暖黄平光）构图视角（如：极度仰视、中心对称、广角畸变）材质细节（如：生锈的金属、半透明的磨砂玻璃）色彩情绪请先给我方案，我选定一个后，你再帮我写成最终的英文 Prompt。”

-纯靠输入决定输出。

比如，

想法： 一个人在喝咖啡。精致化 Prompt： 一个孤独的男人在深夜便利店喝咖啡，Edward Hopper style (爱德华·霍普风格，孤独感)，窗外是Cyberpunk (赛博朋克) 的霓虹灯雨夜，Cinematic lighting (电影布光)，Kodak film grain (柯达胶片颗粒)。

你要是不知道这些，那是真说不出来的……
