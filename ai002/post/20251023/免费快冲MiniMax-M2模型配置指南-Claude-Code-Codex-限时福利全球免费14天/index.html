简单来说，M2有几个主要亮点：

  1. 定位精准： 这是一个专为编程和Agent打造的模型。

  2. 性能强悍： 在全球权威模型评测榜单 (Artificial Analysis) 上，它直接冲到了全球前五，开源模型里排名第一。

🛠️ 教程一：接入 Claude Code

让 Claude Code (CC) 使用 M2 模型非常简单，只需要改一个配置文件。

第一步：获取 API Key

你首先需要一个 MiniMax 平台的 API Key。

  1. 访问 MiniMax 开放平台并注册账号：https://platform.minimaxi.com/user-center/basic-information/interface-key

  2. 在后台创建一个新的 API Key。

  3. 立即复制并保存好这个Key（它只会显示一次）。我们后面叫它 <你的MINIMAX_API_KEY>。

  • Windows 系统:C:\Users\你的用户名\.claude\settings.json

  • Mac 系统:~/.claude/settings.json

🛠️ 教程二：接入 Codex

接入 Codex 的步骤类似，但需要设置“环境变量”，我们一步步来。

第一步：获取 API Key

同上。如果你在配置 Claude Code 时已经获取了，请跳过此步。

第二步：找到 Codex 配置文件

这个文件叫 config.toml。

  • Windows 系统:C:\Users\你的用户名\.codex\config.toml

第四步：设置环境变量 (关键)

Codex 需要通过“环境变量”来读取你的 API Key。

  1. 打开你的“终端”工具：

  • Mac 系统： 打开 “Terminal” (终端)。

  • Windows 系统： 打开 “PowerShell”。

  1. 在终端里执行以下命令（注意替换你的Key）：

  • Mac (或 Linux) 用户执行:

    <span leaf="">$env:MINIMAX_API_KEY = "&lt;你的MINIMAX_API_KEY&gt;"

注意： 这一步是告诉你的电脑，MINIMAX_API_KEY 这个“暗号”对应的值是你的Key。

第五步：启动 Codex

现在，Codex 也会默认使用 MiniMax-M2 模型了！
