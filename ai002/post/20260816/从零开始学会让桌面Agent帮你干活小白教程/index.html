从零开始，学会让桌面Agent帮你干活！【小白教程】

2026年8月16日
| 阅读

雷猴啊朋友们！

会用 Agent，是今年所有人都绕不过去的话题。

但说实话，90% 的朋友还停留在拿 AI 提问、聊天的阶段，所以今天，就是一期专给白领的——桌面 Agent 办公提效全教程！

之前我也出过海外 Codex、Claude Code 的教程，但很多朋友卡在了注册这一步。

所以这次我们换成最新的国产桌面端 Agent——Kimi Work，

用实际的日常办公案例，带你一次拉通桌面端 Agent 的八大能力。

文章里的提示词我也整理好到文档啦~👇

**https://my.feishu.cn/wiki/Z9cXwHd3tiIAgJkHnKAcZD06nUf**

我们现在开始！

桌面 Agent 的优势

桌面 Agent 的优势是它把 AI 放进你的真实工作环境里，让 AI 不只是回答问题，而是可以：读你的东西、改你的东西、运行你的东西、验证自己的修改。

所以它本质上是从聊天机器人升级为有权限、有工具、有反馈闭环的数字员工~

第一大能力：操作本地文件

我们今天用到的桌面 Agent 是 Kimi Work，在 Kimi 官网安装登录就行~

打开之后，它有两个模式，

  1. Chat：就相当于你在浏览器里打开 Kimi 官网，没什么区别

  2. Work：才是今天的主角——真正运行在你电脑上的 Agent

2.1 让 Agent 读写本地文件

我们点新建项目，可以选一个已有的本地文件夹，也可以新开一个文件夹，作为这个 Agent 的项目工作区。

比如我打开一个文件夹，

里面存了一个 Excel 表格，是所有 985、211 近三年的各省分数线。

这本来是我想帮表妹分析志愿该填哪个学校的，但这张表太乱了，年份、省份、学科全混在一起，自己对比特别费劲。

于是，我们就让 Kimi Work 直接帮我们改表格，那如果你不想 Agent 的每个操作都手动点同意，可以选“全部允许”的权限。

OK，它就直接在文件上动手了。

我们在 WPS 里能看到，表格已经变了：这个分数段能报的学校筛出来了，也排好序了，甚至还帮我们上了颜色，非常清晰。

2.2 继续生成可编辑 PPT

接着我还想做个 PPT，就继续让它基于这张表，把挑出来的几所学校做成一份志愿填报建议 PPT，方便发到家族群里讨论。

它会自己读取表格，又新建了一个 PPT。

我们在项目文件夹中可以直接看到它新建的 PPT，打开后也是可编辑的 PPT 格式，要求做的可视化图表也放进去了。

目前看来 Kimi Work 做 PPT 的能力还是不错的~

2.3 命令行和文件格式处理

同时，桌面端 Agent 也可以操作你的命令行，帮你下载安装软件、执行脚本，包括压缩图片视频、转换文件格式。

这些原来很琐碎的电脑操作，现在也可以交给 Agent 来做。

第二大能力：操控浏览器

不过很多时候，光靠我们自己的资料还不够，还得上网查信息。

这就可以用到它的第二大能力——操控浏览器。

我们找到 WebBridge，根据指引安装好浏览器插件之后，它就能操控浏览器，而且用的是我们自己带着登录态的浏览器。

所以像需要登录的社交媒体网站，不开放 API 的网站评论，它都能拿到。

比如刚才那批学校筛出来后，我还想知道它们的王牌专业、保研就业、宿舍口碑怎么样——这些信息都得看网上真实的评价。那就接着让它去社交媒体查，再把信息更新进 PPT，做一份择校推荐的参考。

它自己会打开浏览器，搜索、点击全是它在干，这期间我们就算用浏览器去干别的，也不影响它。

最后我们再验收，PPT很全面了~

而且除了查信息，WebBridge 还能替我们做些繁琐的网页操作，比如一口气帮你关注 100 个博主～

第三大能力：多个 Agent 分头去干

当你的资料一多、要搜的内容一多、活的体量一大，单个 Agent 干起来就有点费力了。

这时候，就可以上集群，让多个 Agent 分头去干。

Agent集群是 Kimi 的一个特色，最多能一次拉起 300 个 Agent 一起干活。

比如做电商的朋友，618 大促结束要复盘。手里的文件夹有订单、投放、退款、客服、物流、财务数据，还有一堆会议纪要和老板反馈，一个 Agent 都读不完这些文件。

那我们就打开这个电商复盘项目，选择 Agent 集群，让它来做一次全面复盘，最终给到报告。

它会自动拆成很多个不同专长的 Agent，分头去看这些文件，最后整合出结果。  

你看，一份数据复盘报告、一个 PPT 报告，还有老板可能追问的 Q&A ，一口气都给我们非常详细地做出来了～

从总结摘要、整体达成情况，到流量投放分析、退款原因分析等等，报告里都整理得很详细。

PPT 也是图文并茂，关键数据都做成了图表，拿去汇报基本没啥问题了。

Agent 集群特别适合数据多、调查深、要产出的东西也多的场景。

比如这是我让它整理的苹果所有年份的产品策略，它全查出来了，自动调研太方便～  

还有公司整套的弱电方案，你瞧瞧这些都是它自己做的，考虑非常详尽～

不过，集群目前需要 99 元/月以上的会员才能用~

 第四大能力：Goal 模式

除了 Agent 横向数量上的拓展，也可以让 Agent 在纵向上长时间深度干活。也就是这次很重磅的新能力：Goal 模式。

普通的模式下，Agent基本上几分钟完成一个小步骤，顶多干个几十分钟，就在等着人类给它反馈，帮它纠错。每一步都在等着你推动。

但Goal模式不一样，你给它一个明确的任务终点，你就可以不管了，它自己持续的花几个小时，甚至十几个小时，把整个事情走到底。

做计划、动手做、检查结果、再返工、再重来，一轮一轮对照着目标和验收标准循环下去，直到做完为止。

比如说，我们可以先跟它把一个项目讨论清楚、形成这样一份详细的需求文档和验证标准，放进项目里， 

然后开启 Goal 模式，让它对照着 PRD 一条一条做完，并一条条检验；

那中途我们睡个觉休息一会，等回来之后，你看，最后的结果基本都完成了。接下来我只需要负责验收就行，

我们一一对照一下，标题，时间轴效果也不错，前后对比的组件也可以拖拽，联系我的链接也可以自定义，以及还有这么多组件我们可以自己选择添加，整体完成度还是可以的，

说白了，Goal 就是把整个项目的目标和验收标准都交给它，让它一直负责到底，最后你来验收结果。这就很适合每天睡前下个 Goal ，早上来验收~

第五大能力：插件

除了通用的工具和纵横两种方式，你也可以再给 Agent 配上一些特定的插件，

Kimi Work 就提供了一些可以接入的，比如飞书、钉钉、Canva、WPS等等，安装很简单，点一下就行。

我连上飞书插件之后，就能直接让它把刚才那份 618 复盘，整理成一个带详细数据看板的飞书多维表格发给老板。

你看，直接就发出去了，

还帮我们拆成了十几个表和视图，这都能手动编辑。最后给老板看的仪表盘也很漂亮；这些原来我们自己手动做真的很费时间 ～ 

因为我还装了 Canva 插件，所以也可以直接一句话让它把项目里的复盘数据，做成一张战报海报。

而且点开链接，整张图会直接放进 Canva 里，随时可以继续修改。

另外，它的插件里还有新出的 Computer Use，它比浏览器操控更通用，能直接在你的电脑桌面上做系统级的操作，去操控其他软件。

第六大能力：Skill 

第六大能力，就是 Agent 里非常实用、大家也比较熟悉的 Skill 技能。

我们点左上角就是技能了，你可以点开技能文件夹，就能上传你常用的Skill。

当然，Kimi Work 官方自带了不少好用的 Skill。

推荐技能里这两个就挺好用：guizang-PPT-skill 能把你的 PPT 样式做得更漂亮；Equity Researcher 能帮你输出机构级的投研报告。

那我们先把这两个技能都安装上，先试个PPT优化的Skill吧，我们直接点击使用，让它优化一下刚才那份志愿填报 PPT，

这是对比~立马就从一个普通 PPT，变成了风格强烈、排版精致的样子。

而 Equity Researcher 做出来的研报是这样的，质量也很高。

第七大能力：给它立一本员工手册

如果说技能解决的是Agent在特定任务上做得好不好，那接下来的Agents.md文件，就是管好Agent在整个项目中的行为。

Agents.md 是一份Markdown文档，其中的内容会在 Agent 做任何事之前，被优先注入到提示词里，相当于一份系统提示词。

但它能自定义的程度，比很多朋友想的高得多，有点被低估了，我们甚至可以靠 Agents.md 的机制，搭出一整套有长期记忆的系统。

你可以自己在项目文件夹里手动建，也可以让 Kimi Work 帮你建。

具体内容怎么设计，这个思路就比较灵活和复杂了。

文末我会给大家一个小的系统模板，它会让你的 Agent 在复杂任务下，先给你出 PRD 确认，以及不盲目地肯定你，并且会随时记录决策和记忆，还可以有序地帮你组织项目文件~

第八大能力：定时任务

那当你把 Agent 用到这一步，它已经是工具齐全、办事有规矩的程度了。

所以也许，你会希望它更省心一点，到点自动开工，也就是定时任务。

直接在"定时任务"里点新建，输入任务和需求就行。比如每天早上 8 点读我的飞书日历、生成今天的日程看板；

或者每天帮我查看国庆的机票价格，低于799就发飞书消息提醒我下单等等~

到这里，桌面端 Agent 从入门到进阶的这些能力，你基本都了解了。

当然，Kimi Work 还是 Beta 版，还做不到"甩给它就百分百交付"，这点得有预期。

那最后，我们简单回顾一下桌面端 Agent 逐步增强的八大能力~
