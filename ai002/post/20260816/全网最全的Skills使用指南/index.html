🧠什么是 Skill？

Skill 是 Claude Code 的可复用能力扩展包——本质是一个包含 SKILL.md 指令文件、脚本和资源的文件夹。装上 Skill 后，Claude 在遇到相关任务时会自动加载这些专业能力，不用你每次重复解释。 

📦

Claude 按需加载

🔄

一次配置
终身复用

**💡 核心区别：**普通 Prompt 是「建议」，Skill 是「带流程的模块」——它让 AI 先想清楚再动手，而不是直接开始写代码。

🧠Pro Tips

🎯 Tip 1：好的 Skill 只做一件事

一个 Skill 只解决一个问题。description 要像路由规则（“当用户说 X 时激活”），不是宣传语。

📦 Tip 2：善用 references/ 分层

核心 SKILL.md 保持精简（< 5k tokens），细节推到 references/ 目录按需加载，避免白白消耗上下文。

🔍 Tip 3：先装官方，再装社区

从 anthropics/skills 开始，熟悉后再去 obra/superpowers 找实战技能。

🧹 Tip 4：定期清理

装 50 个 Skill 不如留 5 个精的。定期用 /plugin list 检查，删掉用不上的。

❓常见问题

Q：Skill 和 Slash Command 有什么区别？

Slash Command（如 /compact）需要你手动输入触发；Skill 是自动触发的——Claude 根据对话内容判断是否需要加载。

Q：装太多 Skill 会影响性能吗？

每次请求 Claude 只用约 100 tokens 扫描所有 Skill 的 name 和 description，代价很小。但好的 Skill 是精准的，装太多反而不容易激活对的。

Q：Skill 和 MCP 什么关系？

Skill 是教 Claude 怎么做（指令+流程），MCP 是让 Claude 能做什么（连接外部工具如 GitHub、数据库）。两者可以配合使用。

Q：怎么判断一个 Skill 值不值得装？

问自己：没有这个 Skill，这件事会让我多花多少时间？答案是「5 分钟以内」的，大概率是噱头。
