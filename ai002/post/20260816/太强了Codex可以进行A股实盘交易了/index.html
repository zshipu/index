太强了！Codex可以进行A股实盘交易了

2026年8月16日
| 阅读

想用 AI 帮你盯盘和炒 G？今天，它终于可以实现了。

实现思路

先说实现思路：

  1. 开通证券公司的 QMT（Quantitative Market Trading，量化市场交易）权限。

  2. 安装 QMT 客户端，登录你的账号。

  3. 安装 QMT Skill 技能。

  4. AI 直接帮你买卖 GP。

实现原理

它的实现原理也不难，如下所示： 

  1. AI（Codex）调用 QMT Skill 技能（底层是 Python 代码）。

  2. QMT Skill 技能使用 TCP 通讯协议调用 QMT 客户端，使用你的账户信息，对指定的 GP 或 ETF 进行买卖操作。

如何开通QMT权限？

不同的证券公司开通权限也是不一样，目前门槛比较低的是某金证券，只需要在线开通其证券账户，然后再存入10万元就可以开通QMT权限了，如下图所示： ![[Pasted image 20260626181523.png]]![[Pasted image 20260626181646.png]]

交易技能如何安装？

直接将以下提示词发送给你的 AI（Codex），它就可以自动安装了：

“

请先检查是否已安装 SkillHub 商店，若未安装，请根据 https://skillhub.cn/install/skillhub.md 安装SkillHub商店，但是只安装CLI，然后安装miniqmt技能。若已安装，则直接安装miniqmt技能。
