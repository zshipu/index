用好Agent，先从这4招开始！【小白教程】

2026年8月16日
| 阅读

雷猴啊～

想用好Agent，先从这四类任务开始！

检查、梳理、执行、观察～

这其实也是白领工作中最常见和耗时的四大类型，只要跟你的工作对上号，立马就能提效！

接下来我们开始~

工具介绍

考虑到更多的朋友用Codex之类的门槛比较高，今天选的呢，是近期很多小白在用的百度搭子 DuMate，它是办公专用的Agent，我们可以直接在官网下载桌面端、应用商店下载APP。

**https://www.dumate.cn/**

两端记忆还是通的~

那国产的一大好处，就是它里面有更多好用的国产APP插件和Skill，

搭子还有长期记忆系统，会越来越懂你。

再一个就是每天签到，它还送500个积分，加上它的Harness很省token，这个还挺经用的～

第一类：检查

ok，那我们要说的第一类任务，检查。

2.1 什么是「检查」任务？

这类任务也就是找出各种资料中的问题，

  • 做自媒体的，检查下文稿里有没有错别字、病句、违禁词。 

  • 做财务的，检查表格里有没有格式不统一、空数据、计算错误的项。

这类任务想让Agent做好，关键是明确“检查什么问题”，“审核的标准是什么”，“是直接修改还是报告”。

2.2 检查合同

我们拿检查合同来演示。在搭子这里选择一个工作区，也就是你本地的一个文件夹，

那本地呢有我的合同、报价单和供应商资料，这时可以直接跟它说：

检查合同里面填的信息：

1.报价和项目名（问题主体）是否跟报价单一致（标准）

2.收付款账号和主体名称是否跟供应商资料一致

3.再找出合同里所有对我们不利的条款，并按照公平的原则，直接在文档中用批注的方式给出你的修订建议。

搭子就会直接去读取你本地的这几个文件做检查，

最后在这个合同上去修订批注，

我们看完最后拍板就行了~这就是检查任务！

第二类：梳理

3.1 什么是「梳理」任务？

梳理，也就是把杂乱的信息按逻辑整理成能直接用的东西。

比如说：整理网上的信息，变成一个调研报告；或者整理本地的发票文件，变成一个详细的表格～

那这类任务的关键，是给Agent说清楚“根据哪些资料”，“按什么逻辑”，“整理成什么格式”。

3.2 做一份电车竞品报告

比如说我们本地存着我们自己的产品介绍，还有一些用户反馈，那我们要给领导汇报一下我们跟市场上其他电车的竞品对比报告。那我们就可以跟搭子说，

那搭子呢还有个好处，我们也不用把提示词写得特别长，因为有不清楚的，它还会主动以提问的方式来采访我们。

那我们再告诉它希望是全面的对比之后，它就会开始自己搜索。

搭子的国内数据还是比较全的，普通搜索很难搜到公众号内容，但它能，

搭子也还有浏览器自动化工具，自己可以打开网页去看。

那最后，这是我们的报告，整理的逻辑很清晰，PPT也很详细还有图表~

第三类：执行

4.1 什么是「执行」任务？

第三类，执行 ，也就是按一系列流程把活儿干好～

比如流程短的“订个机票、酒店、饭店”，流程长的比如“调研到写稿到出图做自媒体内容”。

下达这类任务的关键，是把目的说清楚，流程和规范给点指导，结果要求清楚，还要给它必要的工具/资源～ 

4.2 团建餐厅推荐应用

比如我们下周小组团建，想做个餐厅推荐的应用来成员投票，这时候跟搭子说。

然后在技能与套件这里，选上百度地图、秒搭应用开发、UI/UX设计专家，前端创意设计工具。

这些就是给它的工具和资源了。

4.3 给 Agent 配工具

那这些工具和资源从哪来的呢？我们点开能力拓展这里，

内置技能中就有一大堆我们熟悉的国产应用，

点开“我的”，可以看到这里还可以连接很多应用，

比如我连接了飞书，所以它可以直接帮我发送消息到群里。

大家就根据自己的任务，在这里面给它挑工具就好了。

4.4 长期记忆：减少重复交代背景

那可能有人会问，刚才我的提示词，它是怎么知道我的口味是什么，以及我的公司在哪里的呢？

诶，这就是搭子的另一个好处，长期记忆。我们在左下角选择记忆，

这里面我已经存好了关于我们的个人信息，和我对搭子的人格设定。

这些记忆，它干任何活都会自动带着，你可以自己手动编辑，也可以在跟搭子的对话中，让它自己记录。

同时，它还有一层记忆，主动记录着我们的关键决策和偏好，用着用着搭子也会越来越了解你。

ok，我们现在来看下成品效果，网页做得挺可爱的！

也能投票，投票的结果能实时查看～执行得很不错。

4.5 自媒体套件

搭子里面也有一个现成的自媒体套件，包含了能帮你执行自媒体所有环节的技能和工具 ～

比如我只跟它说了一条指令，说我要做趣味历史。

它就逐步引导我做选择细节，最后一口气图文排版都做好了，成了这样一篇小红书图文和公众号文章！ 

那这就是结合技能和插件的执行任务！

第四类：观察

那最后一类，观察，也就是帮你注意外界的变化，并且采取行动。

比如说，8点提醒我开会， 领导来了就把我叫醒之类的～ 

这类任务的关键：是把"什么情况"就"干什么"的监测条件定清楚。

比如近期有朋友追某某科技的股票，但希望它在某个预期价位的时候再入手。

那你就可以点击自动化，这里就是搭子的定时任务，

我们可以创建个新任务，给它起个名字，写下我们的任务指令，

那每天它都会定时地去执行这个查询的动作。不过由于股价从来没低于46，所以它一直都是保持静默的状态。

为了演示我改了条件，让它触发了一下，手机端和电脑端都通知了～ 

那当然了，这四类任务，远远不止我举例的这些用法～ 

搭子能做到的任务上限，也可以更复杂。

但想要用好Agent，不用追求复杂和过度自动化，先从这四类任务开始，解放你的日常工作～

好啦！我们下次见～
