准备好了吗？我们开始

如果你用过 ChatGPT、Claude 或者国内的 DeepSeek、Kimi，你一定体验过大语言模型的强大

但用久了，你可能也发现了一个问题：它只能用来对话，最后干活的还得是咱自己。另外就是，它好像什么都会一点，但什么都不够专

一个典型场景

比如你想让 AI 帮你写一篇公众号文章。你打开对话框，开始输入：

帮我写一篇公众号文章，主题是关于时间管理的，要有吸引力的开头，中间分几个小点来讲，结尾要有金句，风格要轻松但不油腻，字数控制在2000字左右……

写完这段提示词，你可能已经花了两分钟
AI 给你生成了一篇，你看了看，觉得开头不够抓人。于是你又说：

“开头换一个方式，用一个具体的场景切入……”

来回几轮之后，文章终于差不多了。但下次你再写公众号，这个过程又要重复一遍

问题的本质是什么？

大语言模型是通才，不是专家。每一次对话，它都是从零开始理解你的需求。它不知道你喜欢什么风格，不知道公众号文章有什么套路，不知道你上次满意的文章长什么样

你需要反复地、详细地告诉它——这就是为什么很多人觉得"AI 是很强，但用起来好累"

有没有一种方式，让 AI 一上来就知道该怎么做？

有。答案就是 Skill

你可以把 Skill 理解成给 AI 装的"外挂"，或者说App

手机买回来的时候，它什么都能做一点，但你要拍好照片得装个专业相机 App，要剪视频得装剪映，要点外卖得装美团。装上 App 之后，手机就变成了某个领域的专家

Skill 对于 AI 也是一样的道理。

当你给 Claude Code 装上一个"公众号写作助手"的 Skill 之后，它就自动知道：

  • 公众号文章的标准结构是什么

  • 开头应该怎么写才能吸引读者

  • 什么样的标题点击率高

  • 怎么排版适合手机阅读

你不需要再写一大段提示词。你只需要说"帮我写一篇关于时间管理的公众号文章"，它就能直接给你一篇结构清晰、风格合适的成品。

这就是 Skill 的价值：把专业能力打包好，让 AI 开箱即用

本文将从零开始，带你完成三件事：

  1. 安装 Claude Code：一个可以运行 Skill 的 AI 工具

  2. 配置大语言模型：给 Claude Code 接上"大脑"

  3. 下载并使用 Skill：让 AI 真正变成你的专属助手

二、核心概念：什么是 Claude Code 和 Skill？

在正式动手安装之前，我们先花几分钟搞清楚两个核心概念：Claude Code 和 Skill

理解了它们是什么、为什么这样设计，后面的操作你会更加心中有数

Claude Code 是什么？

Claude Code 是 Anthropic 公司推出的一款官方工具。Anthropic 就是 Claude 大模型的开发商，你可能在网页上用过 claude.ai，那就是他们家的产品

简单来说，Claude Code 是一个运行在"命令行"里的 AI 助手

看到"命令行"这三个字，你可能已经开始紧张了——这是不是程序员才会用的东西？别担心，我来解释一下

命令行是什么？

你平时用电脑，大部分操作都是"点点点"——点开文件夹、点开软件、点击按钮。这叫做"图形界面"

命令行则是另一种操作电脑的方式：你输入一行文字指令，电脑就执行相应的操作

比如你想打开一个文件夹，在图形界面里你是双击文件夹图标；在命令行里你是输入 cd 文件夹名称，然后按回车。结果是一样的，只是操作方式不同

命令行听起来很"极客"，但其实非常简单——本质上就是打字。后面的教程里，我会给你准备好所有需要输入的命令，你复制粘贴就行

为什么 Claude Code 要做成命令行工具？

你可能会问：既然网页版的 Claude 也能用，为什么还要搞一个命令行版本？这是因为命令行版本有几个网页版做不到的优势：

  1. 可以直接操作你电脑上的文件
    网页版的 Claude 只能处理你复制粘贴给它的文字。但 Claude Code 运行在你的电脑上，它可以直接读取和修改你的本地文件。比如你有一个文件夹里放着 100 篇文章，你想让 AI 帮你全部整理一遍——用网页版你得复制粘贴 100 次，用 Claude Code 一句话就能搞定

  2. 可以自动化执行复杂任务
    Claude Code 可以把多个步骤串联起来自动执行。比如"先读取这个文件，然后分析内容，最后生成一份报告并保存"，这种连续操作网页版做不了，Claude Code 可以

  3. 可以安装 Skill，获得专业能力
    这是最关键的一点。网页版的 Claude 就是一个"裸奔"的通用助手，但 Claude Code 可以通过安装 Skill 来获得各种专业能力——这正是本文要教你的

Skill 是什么？

在开篇部分，我用了一个类比：AI 是手机，Skill 是 App。现在让我更准确地解释一下。

Skill 本质上是一套"预设的指令和知识"。

你可以把它想象成一份详细的"工作手册"。当你安装一个 Skill 之后，AI 就相当于读过了这本手册，知道在特定场景下应该怎么做。

举个例子，一个"公众号写作助手"的 Skill 里面可能包含：

  • 公众号文章的标准结构模板

  • 10 种经过验证的爆款开头写法

  • 标题优化的技巧清单

  • 不同类型文章（干货、故事、观点）的写作套路

  • 排版规范和注意事项

当你让装了这个 Skill 的 AI 写公众号时，它不是从零开始瞎写，而是基于这些预设的知识来输出。所以结果会更专业、更稳定

Skill 的本质价值是：把专家经验打包，让 AI 可以复用

你不需要自己总结这些经验，也不需要每次都写一大段提示词。有人已经帮你把最佳实践整理好了，你只需要下载安装，就能让 AI 变成这个领域的"专家"

使用 Skill 的两个前提

了解了 Claude Code 和 Skill 是什么，你现在应该明白：要使用 Skill，你需要先有一个能运行 Skill 的环境。具体来说，有两个前提条件：

前提一：安装 Claude Code
Skill 是运行在 Claude Code 里的（就像 App 运行在手机里）。所以你首先需要把 Claude Code 安装到你的电脑上。

补充说明：除了 Claude Code，市面上还有一些类似的开源工具，比如 OpenCode。它们的功能大同小异，也能运行 Skill。本文以 Claude Code 为主来讲解，因为它是官方工具，稳定性和兼容性最好。

前提二：配置大语言模型
这一点很多新手会忽略。Claude Code 本身只是一个"壳"，它需要连接一个大语言模型才能工作。你可以把 Claude Code 想象成一个聪明的"身体"，大语言模型则是它的"大脑"。没有大脑，身体再好也没用。

你可以选择连接不同的"大脑"：

  • Anthropic 官方的 Claude 模型（国内也有一些中转站提供 Claude 模型）

  • 国内的 DeepSeek、Kimi 等模型

  • 通过 OpenRouter 中转使用各种模型

具体怎么配置，后面会详细讲。现在，让我们开始动手

四、安装 Claude Code

首先，你需要打开一个叫"终端"的软件。

终端是什么？
终端就是一个可以输入文字命令的窗口。你在里面输入指令，电脑就会执行相应的操作。它的界面通常是黑色或白色背景，上面显示一些文字，看起来有点"黑客风"

不同操作系统里，这个软件的名字略有不同：

  • Mac 上叫 “终端”（Terminal）

  • Windows 上叫 “命令提示符” 或 “PowerShell”

下面我分别说明怎么打开它

【Mac 用户】如何打开终端

方法一：使用聚焦搜索（推荐）

  1. 同时按下 Command + 空格键，会弹出一个搜索框

  2. 输入"终端"或"Terminal"

  3. 按回车，终端就打开了

方法二：从应用程序打开

  1. 打开"访达"（Finder）

  2. 点击左侧的"应用程序"

  3. 搜索终端

打开后，你会看到一个窗口，里面可能显示类似这样的内容：

这就是终端界面。光标在 % 或 $ 符号后面闪烁，等待你输入命令。

【Windows 用户】如何打开 PowerShell

Windows 有两个命令行工具：“命令提示符"和"PowerShell”。我们使用 PowerShell，因为它功能更强大。

方法一：使用搜索（推荐）

  1. 点击屏幕左下角的 Windows 图标（开始菜单）

  2. 直接输入"PowerShell"

  3. 在搜索结果中点击"Windows PowerShell"

方法二：右键开始菜单

  1. 右键点击屏幕左下角的 Windows 图标

4.1 安装 Node.js

Claude Code 依赖于 Node.js 环境，所以我们第一步是安装它。

【Mac 用户】安装步骤

第一步：下载安装包

  1. 打开浏览器，访问 Node.js 官网：https://nodejs.org/

  2. 点击获取 Node.js。官网提供了两种方式安装，新手推荐直接下载安装包。选择 macOS 版本，下载 .pkg 文件

第二步：安装

  1. 双击下载好的 .pkg 文件

  2. 按照安装向导一路点击"继续"

  4. 看到"安装成功"就完成了

第三步：验证安装是否成功

  1. 打开终端（如果之前关了，重新打开）

  2. 输入以下命令，然后按回车：

  • 尝试关闭终端，重新打开再试一次

  • 如果还是不行，重启电脑后再试

4.2 安装 Claude Code

Node.js 安装好之后，安装 Claude Code 就非常简单了——只需要一条命令

  1. 打开终端

  2. 输入以下命令，按回车：

    <section><span></span><span></span><span></span></section><section><p><span leaf="">npm install -g @anthropic-ai/claude-code</span><span><span leaf="">&nbsp;</span></span></p></section>

  3. 等待安装完成。过程中你会看到一些文字滚动，这是正常的

  4. 当命令执行完毕，光标回到 % 或 $ 后面，就说明安装完成了

验证安装是否成功
输入以下命令：

首次启动会发生什么
第一次启动时，Claude Code 会引导你完成一些初始设置：

  1. 同意服务条款：会显示一段文字，按提示输入 yes 或按回车同意

  2. 选择主题：可以选择界面是深色还是浅色，按个人喜好选择即可

  3. 登录账户：这里会提示你登录 Anthropic 账户或配置 API

Claude Code 的基本界面
成功启动后，你会看到一个简洁的界面：

  • 顶部显示 Claude Code 的标识

  • 中间是对话区域

  • 底部是输入框，你可以在这里输入指令

它的操作方式和网页版 Claude 类似——你输入问题或指令，它给你回答。但因为它运行在命令行里，所以可以做到很多网页版做不到的事情（比如操作本地文件、运行 Skill）

五、配置大语言模型

Claude Code 已经装好了，但现在它还不能工作——因为它还没有"大脑"。这一章，我们来给它接上大脑

5.1 为什么需要配置模型？

前面说过，Claude Code 本身只是一个"壳"，真正的智能来自于它背后连接的大语言模型

你可以把这个关系想象成：

  • Claude Code = 一台没装系统的电脑

  • 大语言模型 = 操作系统

电脑硬件再好，没有操作系统也开不了机。同样，Claude Code 功能再强，没有配置模型也无法回答你的问题

配置模型的本质是什么？
就是告诉 Claude Code：你要用哪个 AI 服务，以及如何连接它。这需要两个信息：

  1. API 地址：AI 服务的"门牌号"

  2. API Key：你的"通行证"，证明你有权限使用这个服务

不同的 AI 服务商，API 地址和获取 Key 的方式不一样。下面我会介绍几种主流方案

5.2 推荐工具：CCSwitch

在讲具体配置方案之前，我想先介绍一个非常好用的开源工具：CCSwitch（地址：https://github.com/farion1231/cc-switch）

CCSwitch 是什么？
CCSwitch 是一个专门为 Claude Code 设计的模型切换工具。它的作用是：

  • 帮你管理多个模型配置（比如你同时有 DeepSeek 和 OpenRouter 的账号）

  • 一键切换不同的模型，不用每次手动改配置

  • 图形化界面，不需要手动编辑配置文件

为什么推荐它？
原生的 Claude Code 配置模型需要手动编辑配置文件，对新手来说容易出错。而 CCSwitch 把这个过程变成了"填表格"——你只需要填入 API Key 和选择模型，它会自动帮你生成正确的配置

如何安装 CCSwitch

  1. 打开：https://github.com/farion1231/cc-switch/releases

  2. 向下滑动这个区域，找到你对应系统的安装包，下载并安装

5.3 方案一：使用国内模型（推荐新手）

如果你在国内，使用国内的大模型是最简单的选择——不需要科学上网，注册和充值都很方便

我以 MiniMax 为例来演示。MiniMax 是目前国内性价比很高的大模型，而且对 Skills 的适配效果很好

第一步：注册 MiniMax 开放平台账号

  1. 打开 MiniMax 开放平台：https://platform.minimaxi.com/login

  2. 点击"注册"，用手机号完成注册

  3. 登录后，你会进入控制台

第二步：获取 API Key

  1. 在控制台左侧菜单，找到 “Coding Plan”（MiniMax 的 Coding Plan 不贵，首月 ¥9.9）

  2. 点击 “创建 API Key”

  4. 系统会生成一串以 sk- 开头的字符串，这就是你的 API Key

  5. 重要：立即复制并保存这个 Key，页面关闭后就看不到了

第三步：配置到 Claude Code

方法 A：使用 CCSwitch 配置（推荐）

  1. 在终端输入 ccswitch

  2. 选择 “添加新配置”

  3. 选择 “MiniMax”

  4. 把刚才复制的 API Key 粘过来就可以了。其他的 CCSwitch 已经帮你填好了

  5. 保存配置。

常见报错及解决方法

  • 报错：Invalid API Key

  • 原因：API Key 填错了，或者 Key 已经失效

  • 解决：重新检查 Key 是否正确复制，确保没有多余的空格

  • 报错：Connection refused / Network error

  • 原因：网络问题，可能是 API 地址访问不了

  • 解决：检查 Base URL 是否正确；如果用的是国外服务，检查网络环境

  • 报错：Insufficient quota / 余额不足

  • 原因：API 账户没有余额

  • 解决：去对应平台充值

六、理解 Skill 的本质

在第二章，我简单介绍过 Skill 是"给 AI 装的外挂"。现在你已经把 Claude Code 安装好、模型也配置好了，让我们更深入地理解一下 Skill 到底是什么。

6.1 Skill 的本质：一份专业的工作手册

想象一下，你新招了一个聪明但没经验的实习生。他很聪明，学什么都快，但刚来公司什么都不懂——不知道公司的工作流程，不知道行业的专业术语，不知道这个岗位的最佳实践

你会怎么带他？

最有效的方式是给他一份详细的工作手册：

  • 这个岗位的职责是什么

  • 常见任务应该怎么处理

  • 遇到问题应该怎么思考

  • 有哪些注意事项和禁忌

有了这份手册，他就能快速上手，输出的质量也会更稳定。

Skill 就是 AI 的"工作手册"。

从技术角度来说，一个 Skill 通常包含以下内容：

  1. 角色定义：告诉 AI 它现在扮演什么角色（比如"你是一个资深的公众号运营"）

  2. 知识库：这个领域的专业知识、最佳实践、常见套路（比如"公众号开头的 10 种写法"）

  3. 工作流程：完成任务的标准步骤（比如"先分析需求→再列大纲→然后分段写作→最后润色"）

  4. 输出规范：结果应该长什么样（比如"标题控制在 20 字以内，正文分 3-5 个小节"）

  5. 示例参考：优秀案例供 AI 学习模仿

当你让装了 Skill 的 AI 做事时，它不是"裸奔"状态下随便发挥，而是基于这些预设的知识来输出。所以结果会更专业、更稳定、更符合预期。

6.2 Skill 能做什么？

理论上，Skill 可以覆盖任何知识工作场景。只要能把一个任务的"专业知识"和"工作流程"总结出来，就可以做成 Skill。

6.3 Skill 和 Prompt 有什么区别？

看到这里，你可能会有一个疑问：

“你说的这些，我用 Prompt 不也能做到吗？我把要求写详细一点，把最佳实践告诉 AI，不就行了？搞一个 Skill 出来，不是多此一举吗？”

这个问题问得很好。让我来解释一下 Skill 和 Prompt 的本质区别。
先说结论：Skill 是"可复用的、系统化的 Prompt 工程"。

单次 Prompt 确实可以让 AI 做很多事。但当你需要反复做同一类任务时，Skill 的优势就体现出来了。

区别一：一次性 vs 可复用

  • 用 Prompt 的方式：每次写文章，你都要输入一大段要求（“帮我写一篇公众号文章，主题是 XXX。要求：开头要……”）。下次再写，又要重新输入。

  • 用 Skill 的方式：所有要求都写在 Skill 里了。你只需要说"帮我写一篇关于时间管理的公众号文章"，AI 自动就知道该怎么写。一个 Prompt 你可能写一次就忘了，但一个 Skill 可以用一辈子。

区别二：零散 vs 系统化

  • 临时写 Prompt，你能想到什么就写什么，很容易遗漏。

  • 而一个好的 Skill，是经过系统梳理的。它包含所有环节、最佳实践、避坑指南和优秀案例。这种系统性，是临时写 Prompt 很难做到的。

区别三：个人经验 vs 专家经验

  • 你自己写 Prompt，用的是你自己的经验。但你可能并不是每个领域的专家。

  • 但如果有一个小红书运营专家，把他多年的经验整理成了一个 Skill——你只要用这个 Skill，就相当于拥有了他的经验。Skill 本质上是"专家经验的封装"。

区别四：不稳定 vs 稳定

  • 同一个 Prompt，AI 的回答可能完全不一样（随机性）。

  • Skill 因为包含了详细的规范和示例，可以大幅降低这种不稳定性，输出更稳定。

区别五：上下文消耗

  • 每次对话，AI 能处理的内容长度是有限的。如果你每次都在 Prompt 里写一大段要求，就会占用很多上下文空间。

  • Skill 的加载方式更高效——它只在需要时才加载相关内容，而且是经过优化的精简版本。

一个类比
如果把 AI 比作一个厨师：

  • Prompt 就像你口头告诉他"今天做个红烧肉，要软烂一点，不要太甜"。

  • Skill 就像给他一本《中餐烹饪大全》，里面有红烧肉的标准食谱、火候控制要点、摆盘技巧、常见失误避坑指南。

口头说当然也能做出菜来，但有了菜谱，出品会更稳定、更专业。所以，Skill 不是"多此一举"，而是"一劳永逸"。

6.4 Skill 存放在哪里？如何被加载？

了解 Skill 的存放机制，有助于你后面安装和管理技能。

Skill 的存放位置
Claude Code 的 Skill 统一存放在一个特定的文件夹里：

  • Mac：/Users/你的用户名/.claude/skills/

  • Windows：C:\Users\你的用户名\.claude\skills\

注意这个路径中的 .claude 是一个隐藏文件夹（以点开头的文件夹在系统中默认不显示）。

一个 Skill 长什么样？
每个 Skill 是一个独立的文件夹，里面包含一些文件。最核心的是一个叫 SKILL.md 的文件，它就是前面说的"工作手册"，用一种叫 Markdown 的格式写成。

Claude Code 如何识别和加载 Skill？
当你在 Claude Code 中执行某个任务时，它会：

  1. 扫描 skills 文件夹，看看有哪些可用的技能

  2. 根据你的输入，判断是否需要调用某个技能

  3. 如果需要，就读取对应的 SKILL.md，把里面的知识"加载"到上下文中

  4. 然后基于这些知识来完成你的任务

你也可以主动告诉 Claude Code 使用某个技能，比如输入"用社交帖子撰写助手帮我写一条帖子"。
