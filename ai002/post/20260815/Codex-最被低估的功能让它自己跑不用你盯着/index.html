Codex 最被低估的功能——让它自己跑，不用你盯着

2026年8月15日
| 阅读

本文涉及的知识点：App 自动化设置 ｜ 定时任务 ｜ 重复工作自动执行 ｜ 自动化场景设计 ｜ 自动化管理

我每次跑完仿真之后要做的事，过去半年没变过。

我是做工程仿真计算的，电子光学、热仿真这些都跑。一次完整的仿真模型跑下来通常要几个小时。跑完之后，我需要手动从十几个输出文件里提取关键参数，检查仿真日志有没有报收敛错误，把结果汇总到表格里，再跟前几次的数据做对比，最后生成分析报告。

整个后处理流程大概四十分钟。不难，但每次仿真跑完都要重复一遍。有时候一天跑两次，那就是一个半小时纯耗在整理数据上。

直到我发现了 Codex App 里的自动化功能。

说实话，这个功能藏在 App 设置里，大多数人根本不知道它存在。我聊过的 Codex 用户里，十个有九个没用过自动化。但用上之后，我的仿真后处理完全交给了 Codex——跑完仿真，它会自动检查日志、自动提取参数、自动生成报告。我只需要看一眼结果对不对。

但自动化不只能做仿真后处理。那些你每天都在做的烦人重复工作——开完会写纪要、下班前憋日报、周五凑周报、定期清理乱成一锅粥的文件夹——全部可以交给它。这一篇我就用四个所有人都能用上的例子，把 Codex App 的自动化功能掰开讲清楚。

一、自动化能干什么

Codex App 的自动化本质上就一件事：设定一个规则，到了时间或触发了条件，Codex 自动执行你指定的任务。

它不需要你打开 App。不需要你守在电脑前。你设定好之后，到点它自己跑。

适合自动化的任务有四个特征：

  • **重复性高。**每天、每周都在做的事。

  • **规则明确。**不需要每次做主观判断。格式固定、逻辑固定的事——最适合自动化。

  • **结果可验证。**跑完之后一眼能看出对不对，不用逐行核对。

  • **做错了代价可控。**别把"自动给老板发邮件"设成自动化。只自动化那些做错了也不会出事故的事。

二、四个你明天就能用上的自动化

自动化 1：开完会自动生成纪要

什么时候跑：手动触发，每次开完会

干什么：把会议聊天记录或录音转文字内容，整理成一份结构化的会议纪要

怎么设：手动触发任务，任务描述：

请根据提供的会议内容生成一份会议纪要，包含：1. 会议主题和时间。2. 参会人员。3. 讨论的主要议题和各方观点（每条不超过两句话）。4. 达成的决议（逐条列出）。5. 待办事项（事项 + 负责人 + 截止时间）。输出为 Markdown 格式，保存为 output/会议纪要-{日期}.md。

你只需要把会议记录粘贴到对话里，或者直接把录音转文字的文件路径告诉它，三十秒出纪要。

自动化 2：每天下班前自动写日报

什么时候跑：每天下午 18:00

干什么：根据当天的工作记录、文件修改记录或对话内容，自动生成日报

怎么设：定时任务，每天 18:00，任务描述：

请帮我生成今天的工作日报：1. 根据今天的对话内容和文件修改记录，整理出今天完成的工作（按事项分类，每条一句话）。2. 列出今天遇到的问题和当前解决状态。3. 列出明天计划推进的事项。4. 用简洁的中文输出，不超过 300 字，保存为 output/日报-{日期}.md。

说实话，写日报是每天最烦的事之一。忙了一天还要坐下来回忆"我今天干了什么"——这种格式固定、内容机械的活，让 Codex 写比你写更快更准。

自动化 3：每周五自动汇总周报

什么时候跑：每周五下午 17:00

干什么：自动汇总本周的日报和工作记录，生成一份周报

怎么设：定时任务，每周五 17:00，任务描述：

请根据本周的日报文件（output/日报-*.md）和项目修改记录，生成一份中文周报，包含：1. 本周完成的主要工作（按项目分类，3-5 条）。2. 遇到的问题和解决情况。3. 下周的重点计划。4. 需要协调的事项（如有）。输出保存在 output/周报-{日期}.md。

以前我每周五下午要花半小时翻聊天记录、查 Git log、回忆这周干了什么。现在 Codex 自动汇总，我只需要花五分钟核对一下。

自动化 4：定时整理乱掉的文件夹

什么时候跑：手动触发，不定期

干什么：扫描指定的文件夹，按类型分类整理，清理过期文件

怎么设：手动触发任务，任务描述：

请整理我的工作目录：1. 扫描文件夹内的所有文件，按类型分类（文档、表格、图片、安装包、临时文件）。2. 列出超过 30 天未打开的文件。3. 给出整理建议（哪些可以归档、哪些可以直接删除）。4. 先输出整理方案，等我确认后再执行。注意：不要删除任何文件，只做移动和归档。

每个人的电脑里都有一个越来越乱的文件夹——可能是"下载"、可能是"桌面"、可能是某个项目的输出目录。手动整理太烦了，交给 Codex 五分钟出整理方案，你点个头它就帮你搬好。

三、设置自动化的三个原则

**铁律一：自动化先从"只读"开始。**先设"生成报告"，别设"自动修改文件"。先让它帮你写日报纪要，等你确认它写得准了，再让它做更复杂的操作。

**铁律二：每次自动化必须有输出。**每个任务结尾都要求它输出一份简洁的报告——扫了哪些文件、发现了什么、做了什么处理。报告 = 你的安全感。

**铁律三：敏感操作永远设为"手动触发"，不设定时。**文件删除、数据修改类操作，设成手动触发。定时只给"只读检查"和"内容生成"。

沙盒和权限画好了 Codex 的活动范围。AGENTS.md 写好了 Codex 的行为规范。自动化让 Codex 开始自己按时干活。三件事全部配好，Codex 不再是一个你需要时刻盯着的工具——它变成了一个能独立执行任务的工程助手。
