Codex 新手保姆级教程，零基础也能快速上手

2026年8月15日
| 阅读

Codex 近年来热度持续攀升，但不少朋友在尝试使用时，都被安装配置、英文文档、AGENTS.md 模板等内容劝退。

今天分享一份专为国内新手整理的详细中文教程，帮你快速跨过入门门槛。

为什么你需要这份教程

Codex 的使用形态多样，包括：

  • Codex APP

    移动端便捷操作

  • CLI 命令行工具

    适合技术用户

  • Desktop App

    桌面端完整体验

  • VS Code 扩展

    开发者日常集成

每种形态的配置方式各不相同，英文官方文档对于不熟悉术语的中文用户来说，阅读成本较高。这份教程以清晰的步骤和截图为主，从零基础到进阶都能跟上。

教程核心内容

1. 国内一键安装配置

针对国内网络环境，教程提供了简化的一键安装方案，无需繁琐的手动配置，开箱即用。

2. 全形态使用指南

涵盖 Codex APP、CLI、Desktop App 以及 VS Code 扩展的完整图文教程，每种形态都配有详细说明和配图，方便对照操作。

3. AGENTS.md 与 MCP Server 实战

AGENTS.md 是 Codex 中定义代理行为的核心配置文件，很多新手不知道如何编写。教程提供了模板示例，并讲解 MCP Server 的配置方法，帮你搭建个性化的智能代理工作流。

4. Skills 使用与高效工作流

Skills 是 Codex 的强大扩展功能，可以大幅提升工作效率。教程结合实际案例，演示如何使用 Skills 以及构建高效的工作流。

5. 常见问题排查

从安装报错到运行异常，教程总结了常见问题的排查思路和优化建议，让你少踩坑。

教程仓库地址：https://github.com/xianyu110/gpt-codex
