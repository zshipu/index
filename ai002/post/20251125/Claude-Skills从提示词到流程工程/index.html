Claude Skills：从提示词到流程工程

什么是 Skills

Skills 是 Anthropic 官方推出的一套 AI 技能规范。

本质上，Skills 是写给 Claude 的"说明书"和"SOP（标准作业程序）"。它把工作中反复执行、有固定流程的任务，拆解成 AI 能理解、能稳定复用、能自动执行的一套流程。

和单条提示词不同，Skills 关注的是任务的可重复性和稳定性。

官方仓库

Anthropic 开源了一个 Skills 仓库：

https://github.com/anthropics/skills

这个仓库的 star 数已经超过 3.2 万。

仓库里放的是 Claude.ai 网页版背后真正在跑的生产级代码。那些功能——“帮我开发一个 Web 应用”、“分析这个 PDF 文档”、“写一个贪吃蛇游戏并预览”——它们的实现逻辑都在这里。

仓库包含三类 Skills

Office Suite（办公自动化）

覆盖 Word、PDF、PPT、Excel 四种格式的操控能力。包括创建、编辑、分析、格式控制、边界处理，每一步都写了 Prompt 结构、参数含义、容错策略。

Developer Tools（开发者工具）

  • • MCP Server 集成

  • • Web 应用测试

  • • Artifacts 构建

  • • 自动化验证流程

这些 Skills 的设计目标是让 AI 参与工程流程，不只是生成代码。

Creative（创意类）

算法艺术、Canvas 设计、主题生成工厂等。重点在于设计思路的可复用性、输入约束、输出稳定性。

技术范式的变化

Skills 的出现标志着一个转变：从提示词工程到流程工程。

提示词工程关注的是"怎么写一句话让 AI 理解"。流程工程关注的是"怎么把业务经验沉淀成 SOP，让 AI 稳定执行"。
