Skills的热重载来了！Claude Code 2.1.0 版本更新日志

2026年1月8日
| 阅读

Claude Code 来到了 2.1.0版本。

Skills现支持热重载，无需重启会话了。

之前我们下载安装一个Skills后需要脱离当前会话重新加载，现在之前复制完就可以使用，从这个版本开始编辑和修改测试Skills更加的方便。

除了热重载，Skills还支持 context: fork 在子代理sub-agent上下文中运行。

说人话就是：可以“继承“”sub-agent系统提示、工具权限和模型配置新开一个“副本”，相当于目前的Skills既可以向下兼容，又能实现向上组合，在组合同时去复用之前的各种配置项，而且避免中间输出占用主会话上下文。

比如可以指定任务在特定类型的子代理中执行：

---
context: fork
agent: data-scientist
---

更多实践案例可以留言一下字节笔记本微信公众号后面的推送。

另外，Claude Code 2.1.0 还新增加一个新的功能language，可以配置响应语言了， 对于不太熟悉英文的朋友是一大利好。

最后是一些小的BUG，如果之前有遇到过可以重点留意一下：

修复敏感数据可能在 debug 日志中暴露的安全问题
修复 OAuth token 刷新相关问题
修复 WSL 环境下 Claude in Chrome 的支持
修复 CJK 字符（中日韩）多行提示的空行问题
大量终端兼容性修复（iTerm2、WezTerm、Ghostty、Kitty）

Claude Code 2.1.0在整体启动性能也得到了很大的优化，终端渲染性能做了提升。

在2版本之后，不太建议使用npm来安装和更新Claude Code了，现在官方推荐使用 Native Installer（原生安装），不需要 Node.js。

安装方法

macOS / Linux / WSL：

curl -fsSL https://claude.ai/install.sh | bash

Windows（PowerShell）：

irm https://claude.ai/install.ps1 | iex

从 npm 迁移到原生安装

如果之前用 npm 装的：

claude install

这个命令会自动迁移到原生版本，配置文件会保留。

后续再更新的话，只需要

claude update

或者重新跑一遍安装脚本也行。

原生安装的好处在于不依赖 Node.js、更稳定、自动更新更可靠，很少会出现之前更新报错的情况，强推！

如果你想系统入门学习Claude Code可以留意一下这个Claude Code官方的视频和我看完后整理的中文文字版本。应该没有比这更权威更好的Claude Code入门教程了
