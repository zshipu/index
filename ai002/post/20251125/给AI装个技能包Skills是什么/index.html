给AI装个技能包：Skills是什么

2026年1月8日
| 阅读

你有没有这样的经历？

每次让 AI 帮你写周报，都要重复解释一遍格式要求。每次让它帮你改代码，都要再说一遍"按照我们团队的规范来"。

烦不烦？

今天聊的这个东西，能彻底解决这个问题。

先打个比方

想象你新招了一个实习生。

第一天，你教他怎么做数据报表：用什么模板、数据从哪拉、格式怎么调。他认真记了笔记。

第二天，你让他做报表。他翻出笔记，照着做，完美。

第三天、第四天……他再也不用问你了，因为他已经"学会"了。

Claude Skills 就是这个"笔记本"。

你把工作流程写一遍，Claude 就永远记住了。下次只要说"帮我做个报表"，它自动按你教的方法来。

再举个生活化的例子

你家的扫地机器人，买回来第一件事是什么？建图。

它先把你家跑一遍，记住哪里是客厅、哪里是卧室、哪里有障碍物。之后每次扫地，它就知道该怎么走了。

Skills 就是给 Claude 的"建图"过程。你告诉它写公众号文章要用什么风格、做代码审查要检查哪些点，它记住了，以后自动按这个来。

和普通提示词有什么区别？

●普通提示词：每次都要手动输入，容易漏、容易错、还占用对话空间。

●Skills：写一次，永久生效。Claude 会自动判断什么时候该用。

就像你不用每次都告诉导航"我要走高速"，它根据目的地自动规划最优路线。

【干货】一个 Skill 长什么样？

Skill 本质上就是一个文件夹，里面放着一个 SKILL.md 文件。

来看一个最简单的例子——周报生成 Skill：

<span leaf="">--- name: weekly-report description: 生成标准化周报。当用户需要周报时自动触发。 ---  # 周报生成技能  生成周报时遵循以下结构：  1. **本周成果**：3-5 个要点 2. **遇到的问题**：2-3 个阻塞项   3. **下周计划**：3 个优先事项  格式要求： - 使用 Markdown - 每个要点不超过 2 行 - 包含具体数据和指标

就这么简单。把这个文件放到 ~/.claude/skills/weekly-report/ 目录下，以后你说"帮我写周报"，Claude 就自动按这个格式来。

【干货】更强大的玩法：带脚本的 Skill

Skills 不只能写指令，还能执行代码。

比如我做了一个"公众号发布 Skill"，它的结构是这样的：

<span leaf="">~/.claude/skills/wechat-publisher/ ├── SKILL.md           # 主文件：定义流程 ├── scripts/ │   └── generate_image.py   # Python 脚本：生成配图 └── templates/     └── styles.json    # 配置文件：CSS 风格

当我说"发布 AI 热点"，Claude 会：

1. 读取 SKILL.md 了解流程

2. 搜索最新 AI 新闻

3. 撰写文章

4. 调用 Python 脚本生成配图

5. 发布到公众号草稿箱

以前这套流程要 2 小时，现在喝杯咖啡的功夫。

【资源】去哪找现成的 Skills？

Anthropic 官方开源了一批 Skills，可以直接用：

官方 Skills 仓库

github.com/anthropics/claude-code/tree/main/skills

社区也有很多优秀的 Skills 合集：

●claude-code-skill-factory - 17 个预设命令模板

●awesome-claude-code - 社区精选 Skills 列表

●wshobson/commands - 57 个生产级命令

官方内置的 Skills

Anthropic 已经给 Claude 装了几个"出厂技能"，不用设置直接用：

●Word 技能：生成带格式的 Word 文档

●PPT 技能：做演示文稿

●Excel 技能：写公式、做数据分析

●PDF 技能：填表、提取文字

总结

Claude Skills = 给 AI 的"技能培训手册"

✓ 写一次，永久生效

✓ 自动触发，不用手动调用

✓ 能包含可执行的代码

✓ 让 AI 变成你的专属助手

你教它什么，它就擅长什么。
