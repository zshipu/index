最近火的一塌糊涂的 Skills 很多群友在问是啥东东

普洱我来简单说八，Skills 就是 Claude Code 的「记忆卡片」。

你把常用的工作流程、代码规范、项目习惯写进去，下次用的时候它就自动记住了。

不用每次都重复交代。

那 Skills 和 MCP 有什么区别？

很多人搞混这两个概念。

MCP 是「能力」，让 Claude Code 能连接数据库、调用 API、操作外部工具。

Skills 是「知识」，告诉 Claude Code 该怎么做事、遵循什么规范。

打个比方。

MCP 就像给你一把锤子，Skills 就像告诉你怎么用这把锤子。

一个是工具，一个是使用说明。

对普通用户来说，Skills 上手更简单。

因为它就是 Markdown 文件，不需要写代码，不需要搭服务器。

写几行文字就能用。

而 MCP 需要一定的开发能力，门槛相对高一些。

我来说说目前最火的 12 个 Skills

最火的12个skills

at-dispatch-v2

这是个底层开发工具，专门用来把 PyTorch 的 AT_DISPATCH 宏转换为新版 v2 格式。

如果你在做 ATen C++ 代码迁移、写 CUDA 内核，这个能帮你自动处理调度宏的升级。

add-unit-support

自动分析源代码并生成完整的测试用例。

它会覆盖边界条件、错误场景和异常情况，还能识别代码中未测试的部分。

skill-writer

帮你写符合规范的 SKILL.md 文件。

包括 YAML 元数据配置、目录结构规范、最佳实践这些。

正文控制在 500 行以内，复杂内容分拆到子文件，这些它都会指导你。

docstring

自动为代码生成标准化的文档字符串和注释。

它会分析代码上下文，理解函数的输入输出、副作用和异常情况，然后生成有意义的文档。

skill-creator

通过交互式对话引导你创建 Skills。

和 skill-writer 不同，skill-writer 是给你规范让你自己写，skill-creator 是一步步问你问题，最后自动生成完整的 Skill。

适合新手，不用记那么多规范。

skill-installer

一键安装社区分享的 Skills。

个人使用放 ~/.claude/skills/，项目专用放 .claude/skills/。

Claude Code 会自动扫描并加载这些目录，无需手动配置。

frontend-design

前端设计专用 Skill。

它不只是给你一堆规范，而是能直接帮你生成生产级的前端代码，避免那种一眼就能看出「AI 味」的通用设计。

hook-development

帮你写 Claude Code Hooks 的 Skill。

包括 PreToolUse、PostToolUse、Stop、SessionStart 这些事件钩子，让你在工具执行前后插入自定义逻辑。

command-development

开发 Claude Code 的 Slash Commands，就是那些用 / 触发的命令。

本质上是预定义的可复用 Markdown 提示词，存储为 .md 文件。

支持 YAML Frontmatter 配置、动态参数、Bash 执行集成这些。

agent-identifier

Anthropic 官方提供的 Agent Skill，帮你开发 Claude Code 插件中的子代理。

涵盖 Agent 结构设计、System Prompt 编写、触发条件定义、工具使用配置。

每个 Agent 都有唯一标识符、触发描述、可用工具列表这些配置项。

rule-identifier

识别和管理项目编码规则，保持代码风格一致性。

可以在项目根目录创建 CLAUDE.md 文件，定义代码组织结构、编码标准、安全措施、测试规范这些持久化规则。

mcp-integration

把 MCP 服务集成到项目里。

MCP 是 Anthropic 推出的开源标准协议，让 AI 连接 GitHub、数据库、Slack 这些外部系统。

MCP 提供连接能力，Skills 定义操作逻辑。一个是插头，一个是说明书。

怎么使用 Skills？

其实特别简单。

Skills 的保存路径有两种。

个人 Skills 放在 C:\Users\你的用户名\.claude\skills 目录下。

这里的 Skills 对你所有项目都生效。

项目 Skills 放在项目根目录的 .claude\skills 文件夹里。

只对当前项目生效。

如果你想快速获取社区分享的 Skills，可以去这个网站看看。

**https://skillsmp.com/zh**

skills合集网站

这是一个 Skills 合集网站，里面有很多现成的 Skills 可以下载。

找到想要的 Skill，点击下载压缩包。

下载skills压缩包

然后解压到你的 Skills 目录下就行了。

解压到skills目录下

下次打开 Claude Code，它就能自动识别这些 Skills 了。

说实话，Skills 的出现让 Claude Code 变得更「懂你」了。

以前每次都要重复交代的事情，现在写一次就够了。

而且社区越来越活跃，好用的 Skills 也越来越多。

如果你还没试过，建议从自己最常用的工作流开始。

比如你的代码规范、提交信息格式、项目结构要求这些。

写成 Skill，以后就省事多了。
