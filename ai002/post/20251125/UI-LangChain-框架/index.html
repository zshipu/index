UI - LangChain 框架

2026年1月8日
| 阅读

您可以通过 Agent Chat UI 使用预构建的聊天 UI 与任何 LangGraph 代理进行交互。使用 部署版本 是最快的入门方式，它允许您与本地和已部署的图进行交互。

在 UI 中运行代理¶

首先，在本地设置 LangGraph API 服务器，或将您的代理部署到 LangGraph 平台。

然后，导航到 Agent Chat UI，或者克隆仓库并在本地运行开发服务器

提示

UI 对渲染工具调用和工具结果消息提供开箱即用的支持。要自定义显示的消息，请参阅 Agent Chat UI 文档中的“在聊天中隐藏消息”部分。

添加人机协作¶

Agent Chat UI 完全支持人机协作工作流。要尝试此功能，请将 src/agent/graph.py 中的代理代码（来自部署指南）替换为这个代理实现。

重要提示

如果您的 LangGraph 代理使用 [HumanInterrupt 模式](https://langgraph.com.cn/reference/agents.1.html#langgraph.prebuilt.interrupt.HumanInterrupt “ HumanInterrupt")进行中断，Agent Chat UI 的效果最佳。如果您不使用该模式，Agent Chat UI 将能够渲染传递给 interrupt 函数的输入，但它将无法完全支持恢复您的图。

生成式 UI¶

您也可以在 Agent Chat UI 中使用生成式 UI。

生成式 UI 允许您定义 React 组件，并从 LangGraph 服务器将其推送到 UI。有关构建生成式 UI LangGraph 代理的更多文档，请阅读这些文档。
