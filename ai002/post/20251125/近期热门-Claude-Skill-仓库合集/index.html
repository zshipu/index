近期热门 Claude Skill 仓库合集

2026年1月8日
| 阅读

前言

最近写了很多 skill 相关的文章，有很多读者问能不能再多分享一些好用的 skill。

一个 Skill，解决 90% 的信息图需求｜支持 Claude code 批量跑，文字还能改

Anthropic 官方最简单的一个 skill，却藏着最高级的提示词技巧

用Claude Code + skill跑通AI+教育的变现闭环｜完整技术拆解

Claude Skill 完全入门指南（200 小时实战，8000 字详解）

用 skill 帮媳妇30秒改完论文格式，我悟出了 AI 时代的终极心法

主打有求必应，我把近期推上比较火热的 skill 仓库都整理了一下，大家按需下载。

Agent Skills 是 2025 年底兴起的开放标准（由 Anthropic 发起），已被 Claude、Cursor、GitHub Copilot、Codex 等多个 AI 编码代理支持。通过 SKILL.md 文件 + 脚本形式，给 AI 代理注入专项技能，让它更好地处理重复性、专业化任务。

以下内容根据分享频率、GitHub Stars、社区反馈（点赞、转发、讨论量）排序，数据截至 2026 年 1 月。

🌟 其他值得关注的仓库

skillmatic-ai/awesome-agent-skills

  • 定位：另一个 Awesome 榜单，强调可组合架构（modular capabilities）

  • 特点：被视为 Agent Skills 的"权威资源库"，适合追求架构优化的开发者

  • 链接：github.com/skillmatic-ai/awesome-agent-skills[7]

kirodotdev/powers

  • 定位：Claude Skills 的强化版（Powers），专为 Kiro 代理设计

  • 特点：按需加载上下文和工具，避免上下文过载，显著提升代理效率

  • 链接：github.com/kirodotdev/powers[8]

TimothyKassis 的 Scientific Skills

  • 定位：科学技能集，专注于科学计算、数据分析、机器学习和金融领域

  • Stars：2.6k+

  • 特点：数值稳定性、模拟、ML 工程等，科研和量化人群超爱用

  • 作者：@TKassis[9]

  • 链接：github.com/TKassis[10]（主页面，含 claude-scientific-skills 相关仓库）
