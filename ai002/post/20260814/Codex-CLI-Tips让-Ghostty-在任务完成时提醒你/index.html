Codex CLI Tips：让 Ghostty 在任务完成时提醒你

2026年8月14日
| 阅读

这段提示词的目标很明确：Codex CLI 完成一轮任务，或等待审批时，macOS 才在 Ghostty 失焦后弹出系统通知。你切到其他标签页或其他应用时能收到提醒，正盯着终端时则不打扰。

01  —

直接复制这段提示词发给Codex CLI

请完整复制，不要删改其中的验证要求：

<span leaf="">请配置「Codex CLI 在 Ghostty 中运行时的任务完成系统通知」，实现后必须验证通知真的能弹出，以我确认收到为准。</span><span leaf=""><br></span><span leaf=""><br></span><span leaf="">参考文档：</span><span leaf=""><br></span><span leaf="">1. https://ghostty.org/docs/vt/osc/9</span><span leaf=""><br></span><span leaf="">2. https://developers.openai.com/codex/config-file/config-advanced</span><span leaf=""><br></span><span leaf=""><br></span><span leaf="">目标：Codex 完成一轮任务或等待审批时，macOS 弹出系统通知；仅在 Codex 终端失焦时通知（切到 Ghostty 其他标签页或其他应用时弹，正盯着时不弹）。</span><span leaf=""><br></span><span leaf=""><br></span><span leaf="">完成标准：</span><span leaf=""><br></span><span leaf="">- 配置 ~/.codex/config.toml，已有 [tui] 区块就合并，不动其他内容；</span><span leaf=""><br></span><span leaf="">- 必须检查 macOS「系统设置 → 通知 → Ghostty」权限，未开启就执行 open 命令打开设置页并指导我开启；</span><span leaf=""><br></span><span leaf="">- 给出 OSC 9 测试命令，让我在 Ghostty 普通标签页执行并反馈结果；</span><span leaf=""><br></span><span leaf="">- 若没弹，继续排查（权限、专注模式、是否在 TUI 内测试等），直到我确认弹出才算完成；</span><span leaf=""><br></span><span leaf="">- 最后提醒我重启 codex 生效。注意：你不能替我点击系统授权框或重启 codex，这些要指导我手动做。</span>

02  —

使用时只记三点

1. 在 macOS 的 Ghostty 环境中，把提示词发给 Codex CLI。

2. 不要只看配置文件：必须在普通 Ghostty 标签页实际执行 OSC 9 测试，并确认自己收到了通知。

3. 系统授权和 Codex 重启需要你手动完成；如果没有弹窗，让 Codex 继续排查权限、专注模式和测试环境。
