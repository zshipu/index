Day 3：导联系统（摄像头的机位）

主题： 医学科普信息图，心电图Day 3：12导联系统——心脏的维度解析（专家共识版） 风格： 干净、专业的医学教材插图风格，结合现代信息图设计。背景为淡雅的医学笔记纸纹理，带有浅灰色的网格和解剖草图底纹。主色调采用了区分度高的双色系统：冷蓝色代表额面（肢体导联），暖橙色代表横面（胸导联）。

核心构图（竖版 3:4）：

1. 顶部核心隐喻：心脏的“全息扫描” (The Holographic Scan) 标题：巨大的黑色无衬线字体“12导联系统：心脏的维度解析”。副标题：“从摄像头隐喻到专家共识：立体心电向量的二维投影”。 中央图像：一个半透明的、发着微光的解剖心脏悬浮在空中。两个巨大的、透明的扫描平面相互垂直地穿过心脏：

  • 一个垂直的蓝色平面（标注：额面 Frontal Plane - 肢体导联）。
  • 一个水平的橙色平面（标注：横面 Horizontal Plane - 胸导联）。 12个风格化的“传感器/摄像头”图标围绕着心脏，6个蓝色在额面上，6个橙色在横面上，射线指向心脏中心，形成一个包围网。

2. 中部左侧模块：额面——六轴系统的构建 (Frontal Plane: The Hexaxial System) 标题栏（蓝色）：额面 (Frontal)：肢体导联与六轴系统。 图像：

  • 爱因托芬三角 (Einthoven’s Triangle)：一个小图展示人体躯干上RA, LA, LL形成的倒三角，标出I, II, III导联方向。
  • 专家共识核心：六轴参考系统 (Hexaxial Reference System)：一个大的圆形图表，将I, II, III（双极）和aVR, aVL, aVF（加压单极）整合在一个中心点。
    • 清晰标注每个导联的正极角度：I (0°), II (+60°), III (+120°), aVF (+90°), aVL (-30°), aVR (-150°)。
    • 用粗蓝色箭头画出正常的**平均心电轴 (Mean QRS Axis)*范围（通常在0°到+90°之间），并特别高亮指向+60°的*II导联。
  • 关键点拨（笔记形式）：
    • “专家视点：II导联通常最接近正常心轴方向 (+60°)，因此波形最‘漂亮’（R波最高）。”
    • “aVR导联位于‘无人区’ (-150°)，几乎总是背离心脏除极波，故P-QRS-T通常全倒置。”

3. 中部右侧模块：横面——胸壁上的巡视 (Horizontal Plane: Chest Wall Survey) 标题栏（橙色）：横面 (Horizontal)：胸前导联与R波递增。 图像：

  • 解剖定位图：一个胸部横断面（CT视角）和前胸壁体表图的结合。清晰标记肋间隙和解剖线，标示V1-V6电极的精准位置（强调V1/V2在第4肋间，V4在锁骨中线第5肋间）。
  • 视野扇区：从V1到V6发出橙色扇形射线，覆盖心脏的不同壁：
    • V1, V2 → 右室/室间隔 (RV/Septum)
    • V3, V4 → 前壁/室间隔 (Anterior/Septum)
    • V5, V6 → 左室侧壁 (Lateral LV)
  • 专家共识核心：R波递增 (R-Wave Progression)：在下方展示从V1到V6的正常QRS波群演变序列。
    • V1：小r深S (rS型)。
    • V3/V4：R波与S波大致相等 (RS型，过渡区)。
    • V6：高R小s或qR (qR型)。
    • 标注一条上升的橙色曲线箭头贯穿R波峰值，文字说明：“正常R波递增：反映左室优势及除极向量由右向左后的移动。”

4. 底部总结模块：记忆锚点 (Memory Anchors) 标题：核心逻辑速记（专家版）。 两个并列的便签框：

  • 左框（蓝调）：“额面看轴向 (Frontal for Axis)”。口诀：“肢体导联六轴定，II导最美aVR反。心轴偏移看I、III，专家共识记心间。”（配指南针图标）。
  • 右框（橙调）：“横面看部位 (Horizontal for Location)”。口诀：“胸前导联横向扫，一二右室三四前。五六侧壁看左室，R波递增是关键。”（配雷达扫描图标）。

整体细节： 所有的导联名称（如aVR, V1, II）都使用清晰加粗的医学字体。重要的解剖部位和共识术语（如“六轴系统”、“R波递增”）有高亮底色或下划线强调。整体画面信息密度高但不杂乱，逻辑线条清晰。
